# كتاب الرياضيات التفاعلي · الصف الخامس الابتدائي

منصة تعليمية تفاعلية عربية (RTL) مصممة لتدريس منهاج الرياضيات للصف الخامس الأساسي عبر محطات تفاعلية، مختبرات بصرية، نظام نقاط وقلوب (Gamification)، ومعلم ذكي اختياري (Gemini AI).

**المعاينة المباشرة (GitHub Pages):** https://omarabotrad97.github.io/interactive-math-book/  
*(يتحدث الموقع تلقائياً عبر GitHub Actions عند كل `push` على فرع `main`)*

---

## محتويات المستودع (Monorepo)

```text
BOOK/
├── index.html              # نقطة الدخول لتطبيق الويب التفاعلي
├── js/
│   ├── main.js             # ربط الأحداث والتنقل العام بين الدروس
│   ├── core/               # إدارة الحالة، الصوتيات، والأدوات المشتركة
│   ├── features/           # المعلم الذكي، الرسوم المفاهيمية، تفضيلات العرض
│   └── lesson1..lesson5/   # منطق الدروس الخمسة ومختبراتها التفاعلية
├── styles/                 # ملفات التصميم المتجاوب (Mobile-First + Tokens)
├── book-mobile/            # تطبيق الموبايل الموازي (React Native / Expo)
├── firebase.json           # إعدادات الاستضافة على Firebase Hosting
└── .agents/                # قواعد ومهارات التصميم المتجاوب للوكيل
```

---

## الدروس والمختبرات (تطبيق الويب)

1. **الدرس الأول (`js/lesson1/`):** القيمة المنزلية ضمن الملايين (خريطة مسار تفاعلية، ملعب الأعداد، تحدٍّ متجدد، تذكرة خروج، وتقرير مهارات).
2. **الدرس الثاني (`js/lesson2/`):** مقارنة الأعداد وترتيبها + مختبر المقارنة التفاعلي (`compare-lab.js`).
3. **الدرس الثالث (`js/lesson3/`):** جمع الأعداد وطرحها + مختبر العمليات العمودية (`add-sub-lab.js`).
4. **الدرس الرابع (`js/lesson4/`):** الأعداد السالبة + مختبر خط الأعداد (`neg-line-lab.js`).
5. **الدرس الخامس (`js/lesson5/`):** خطة حل المسألة (إنشاء جدول) + مختبر الجداول (`table-lab.js`).

## التشغيل المحلي

### تطبيق الويب
بما أن تطبيق الويب مبني بـ HTML/CSS/JavaScript قياسي، يمكنك تشغيله عبر أي خادم محلي بسيط من مجلد المشروع الرئيسي:

```bash
npx serve .
# أو عبر Python:
python -m http.server 8080
```

### تطبيق الموبايل (`book-mobile`)
```bash
cd book-mobile
npm install
npm run web      # أو npm run android / npm run ios
```

## النشر (Firebase Hosting)
المشروع مهيأ للنشر عبر Firebase Hosting:
```bash
firebase deploy
```
