# رحلة الملايين · تطبيق React Native (Expo)

تطبيق تعليمي تفاعلي أصيل لمادة الرياضيات للصف الخامس الأساسي (المنهاج الأردني)، يغطي درس **القيمة المنزلية ضمن الملايين** (الصفحات 8 إلى 11) مع محرك أعداد ذكي، خريطة مغامرة متدرجة، وتكامل مع المعلم الذكي (Gemini AI).

---

## تشغيل التطبيق

من داخل مجلد `book-mobile`:

### 1. التشغيل عبر متصفح الويب (Web):
```bash
npm run web
```

### 2. التشغيل على أجهزة Android (عبر تطبيق Expo Go أو محاكي Android Studio):
```bash
npm run android
```

### 3. التشغيل على أجهزة iOS (عبر تطبيق Expo Go أو جهاز Mac):
```bash
npm run ios
```

## الهيكل المعماري للمشروع (Clean Architecture)

```
book-mobile/
├── App.tsx                     # نقطة الانطلاق وإدارة الحالة العامة وحوار استعادة القلوب
├── app.json                    # إعدادات Expo، الهوية، ودعم الاتجاه العربي RTL
├── src/
│   ├── constants/
│   │   ├── theme.ts            # توكنات التصميم (ألوان الكتاب، مسافات، وظلال)
│   │   ├── places.ts           # دورات ومنازل الأعداد (الآحاد، الألوف، الملايين)
│   │   └── curriculum.ts       # محطات الخريطة الـ 20 والمهام الـ 12 من الكتاب
│   ├── services/
│   │   ├── mathEngine.ts       # محرك النطق العربي، تفكيك المنازل، والصيغة التحليلية
│   │   ├── audioService.ts     # التفاعل الصوتي (expo-speech) والاهتزازات (expo-haptics)
│   │   ├── geminiAI.ts         # المعلم الذكي السقراطي (Gemini API + محرك محلي Offline)
│   │   └── storage.ts          # الحفظ والاسترجاع الدائم (AsyncStorage)
│   ├── components/
│   │   ├── common/
│   │   │   ├── HUD.tsx         # شريط النقاط والقلوب والصوت العلوي
│   │   │   ├── BottomNav.tsx   # شريط التبويب السفلي (المسار، المهام، التحدي، تقدمي، المعلم)
│   │   │   └── Icons.tsx       # أيقونات SVG نقية بدون أي إيموجي
│   │   └── interactive/
│   │       ├── NumberWheel.tsx # خزنة الأرقام الدوارة التفاعلية مع ردود فعل لمسية
│   │       ├── PlaceValueTable.tsx # لوحة المنازل ثلاثية الدورات
│   │       └── PeriodCardSelector.tsx # تكوين الصيغة اللفظية بالبطاقات
│   └── screens/
│       ├── MapScreen.tsx       # خريطة المسار التعليمي (20 محطة بنمط Duolingo)
│       ├── MissionScreen.tsx   # تنفيذ مهام الكتاب الـ 12 بخطواتها التفاعلية
│       ├── InfiniteChallengeScreen.tsx # التحدي اللانهائي وتدريب المهارة الأضعف
│       ├── ReportScreen.tsx    # تقرير تشخيص المهارات وشهادة أسطورة الملايين
│       └── AITutorScreen.tsx   # شات المعلم الذكي (البومة الحكيمة) الصوتي
```
